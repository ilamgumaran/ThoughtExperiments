**Framework-to-Story Translation (never use framework vocabulary in stories):**

| Framework Concept | Story Expression |
|---|---|
| Oscillation | Feelings come and go like waves |
| Interference (∅) | "Strings" — invisible pulls that tug before you think |
| Contraction (↓) | Noticing without following — "The string is there. I don't have to pull it." |
| Null (Ø) | The quiet between — when strings aren't pulling |
| Resonance (≈) | When you're with someone and you don't have to explain yourself |
| Identity interference (∅ᵢ) | "The story I tell about myself" |

## Guiding Principles for This Work

From the essay "On Doing This Work" (`ilamgumaran/thought-org-with-human-ai-hybrid`):
- **Discipline vs Control:** Discipline = chosen constraint in service of an aim. Control = external limitation. The stories model discipline, not control.
- **Honest expression:** Work with genuine uncertainty rather than pretending to have answers. Characters struggle, fail, and don't always find resolution.
- **Resonance:** Connection happens in the present moment. The work itself should embody resonance — not just describe it.
